# Learnia

Personal interactive learning platform — built progressively as both a real product
and a hands-on software engineering learning lab.

- `frontend/` — React + Vite (JavaScript)
- `backend/` — FastAPI + Python (uv)
- `generated-prompts/` — engineering roadmap and phase-by-phase implementation plans

See [`generated-prompts/README.md`](generated-prompts/README.md) for the full roadmap.
